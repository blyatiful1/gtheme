# DAYBREAK — first light

A light desk. Warm white surfaces, the palest sage underfoot, a leaf-green
highlight, and one picture: sunrise coming up through the roof of a glasshouse.
Nothing in it is loud, and nothing in it is dark.

It exists because the first four Looks gtheme shipped were all dark, all
elaborate, and all built out of add-ons and terminal files. Somebody opening
this app for the first time deserves at least one Look that is simply the
desktop, in daylight.

## What applying this Look does

- Sets the wallpaper — the same picture on the desktop and the lock screen,
  over a warm white base colour for the moment before it loads.
- Switches the desktop to **light**, with a green highlight and the stock
  Adwaita window theme, icons and pointer.
- Sets the system fonts to the ones GNOME ships: Adwaita Sans, and Adwaita
  Mono in your command window.
- Sets the warmth Night Light uses to 4200K, which sits under this Look's
  colours without fighting them.

It changes settings and copies one file. It cannot run a program on your
computer.

## What this Look does NOT include

Almost everything, and on purpose. This is the Look that has to work on a
computer where nothing has been installed yet.

**No add-ons.** No dock, no blur, no window effects, no top-bar changes. Every
other Look in this folder turns on between six and eleven GNOME add-ons, each
of which is a download from extensions.gnome.org and a confirmation box. This
one turns on none, so there is nothing to fetch and nothing to agree to.

**No terminal.** It does not write a Ghostty, Ptyxis, Alacritty or starship
configuration, and it does not touch any file belonging to a command window.
The sixteen terminal colours are in `theme.toml` under `[palette]`, so gtheme's
**Terminal** page can offer to apply them to whichever terminal you actually
use — but that is your click, not this Look's.

**No shell theme.** The top bar and the overview keep the shape GNOME gave
them. Changing those needs the User Themes add-on, and this Look has no
add-ons.

**No fonts, icon themes or GTK themes you have to install.** Adwaita, Adwaita
Sans and Adwaita Mono are part of GNOME itself. `adw-gtk3` and Papirus are
lovely and are not here, because a Look that names a theme you do not have is a
Look that half-applies and does not say so.

**It does not switch Night Light on, and it does not switch it off.** It sets
only the colour temperature Night Light uses. If you have it turned on, the
evening will be a gentle 4200K instead of whatever a previous Look left behind;
if you have it turned off, nothing about your screen changes. The switch itself
is yours. (Its warm counterpart in this folder, HEARTH, does turn it on — and
says so.)

## The wallpaper

`wallpaper/daybreak-first-light.png` is drawn, not photographed, so it is ours
to give away: no stock frame and no licence attached to it but this project's
own. It is generated by `tools/gen_daylight_wallpapers.py` in the gtheme
repository — run the script and the same file comes back, byte for byte.

There is no scene in it. It is a graded wash, one soft source of light low and
right of centre, and a fan of shafts leaning out of that source: the ribs of a
glasshouse roof at the hour they stop being dark. The upper left of the frame
is left quiet, because that is where desktop icons and window titles live and a
wallpaper's job is to sit under them rather than argue with them.

The picture is also this Look's tile in the app. That is honest as far as it
goes and no further: it shows you the colours and the wallpaper, not a
photograph of a desktop with the Look applied. Real photography for every
bundled Look is a job still on the list.

### Using your own picture instead

Nothing here is precious. Put your file in this folder and change the two
places that name it in `theme.toml`: the `[[files]]` entry near the top, and
the three `picture-uri` settings that follow, which all read
`file://{{ home }}/.local/share/backgrounds/daybreak/…`. Keep the file name the
same in both places, then run `gtheme validate themes/daybreak`, which will
tell you if you missed one.

Or skip the file entirely and set the wallpaper the ordinary way in gtheme
after the Look is applied. Nothing about a Look is permanent, and Undo puts
back whatever was there before.
