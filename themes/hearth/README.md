# HEARTH — banked embers

A warm desk. Cream walls, sand underfoot, a low amber fire off to the right,
and terracotta as the colour everything important is drawn in. Light, like
DAYBREAK, but the warm end of light rather than the fresh end of it.

It is the other half of the answer to a collection that used to be four dark
rices and nothing else — and, like DAYBREAK, it is built to work on a computer
where nothing has been installed yet.

## What applying this Look does

- Sets the wallpaper — the same picture on the desktop and the lock screen,
  over a cream base colour for the moment before it loads.
- Switches the desktop to **light**, with an orange highlight and the stock
  Adwaita window theme, icons and pointer.
- Sets the system fonts to the ones GNOME ships: Adwaita Sans, and Adwaita
  Mono in your command window.
- **Turns on Night Light** at 3400K, so that in the evening the screen shifts
  towards orange to match the picture. This is the one thing this Look does
  that you will notice after dark rather than straight away — see below.

It changes settings and copies one file. It cannot run a program on your
computer.

## About Night Light

This is the only Look in this folder that touches it, and it is the only part
of this Look that changes how your screen behaves rather than how it is
decorated. Night Light does not change what your screen can show; it warms the
colours in the evening, on GNOME's own sunset-to-sunrise schedule.

It is switched on here because "warm" is the whole idea of this Look and half
of that idea only happens after dark. If you would rather not have it:

- the **Night Light & Timing** page in gtheme's own sidebar switches it back
  off, or
- **Undo** puts back everything this Look changed, Night Light included.

Whichever you use, gtheme recorded what the setting was before it applied this
Look, so going back is exact.

## What this Look does NOT include

Almost everything, and on purpose.

**No add-ons.** No dock, no blur, no window effects, no top-bar changes.
Nothing to download from extensions.gnome.org, nothing to agree to.

**No terminal.** It does not write a Ghostty, Ptyxis, Alacritty or starship
configuration, and it does not touch any file belonging to a command window.
The sixteen terminal colours are in `theme.toml` under `[palette]`, so gtheme's
**Terminal** page can offer them to whichever terminal you actually use — but
that is your click, not this Look's.

**No shell theme.** The top bar and the overview keep the shape GNOME gave
them; changing those needs the User Themes add-on, and this Look has no
add-ons.

**No fonts, icon themes or GTK themes you have to install.** Adwaita, Adwaita
Sans and Adwaita Mono are part of GNOME itself. `adw-gtk3` and Papirus are not
here, because a Look that names a theme you do not have is a Look that
half-applies and does not say so.

**No warm-tinted window theme.** GNOME's orange highlight is as far as the
accent colour goes; the window backgrounds stay Adwaita's. Making the windows
themselves cream would mean shipping a GTK stylesheet, and a stylesheet is the
kind of thing that breaks quietly on the next GNOME release.

## The wallpaper

`wallpaper/hearth-firelight.png` is drawn, not photographed, so it is ours to
give away: no stock frame and no licence attached to it but this project's own.
It is generated by `tools/gen_daylight_wallpapers.py` in the gtheme repository —
run the script and the same file comes back, byte for byte.

There is no scene in it. It is a graded wash, one soft source of light low and
right of centre, and a fan of shafts leaning out of it — a fire seen from
across a warm room, with the room left out. The upper left of the frame is kept
quiet, because that is where desktop icons and window titles live.

The picture is also this Look's tile in the app. That is honest as far as it
goes and no further: it shows you the colours and the wallpaper, not a
photograph of a desktop with the Look applied. Real photography for every
bundled Look is a job still on the list.

### Using your own picture instead

Put your file in this folder and change the two places that name it in
`theme.toml`: the `[[files]]` entry near the top, and the three `picture-uri`
settings that follow, which all read
`file://{{ home }}/.local/share/backgrounds/hearth/…`. Keep the file name the
same in both places, then run `gtheme validate themes/hearth`, which will tell
you if you missed one.

Or skip the file entirely and set the wallpaper the ordinary way in gtheme
after the Look is applied. Nothing about a Look is permanent, and Undo puts
back whatever was there before.
